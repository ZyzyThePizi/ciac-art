# ciac-art

Card art with the printed text removed, used as play-mat backgrounds by CIAC (https://zyzythepizi.github.io/ciac/).
Generated by code (`tools/mat-clean/` in the CIAC repo) and synced with `tools/mat-clean/sync-art.mjs`. Do not edit by hand.

- `clean/index.json`: `{ "<lang>": { "<file id>": "f" | "w" } }` (`f` full-bleed card, `w` windowed art), plus `updated`, `v`.
- `clean/<lang>/<file id>.webp`
